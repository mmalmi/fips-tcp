# fips-tcp-endpoint — frozen

This package is frozen. This final release changes only this notice; its library code is unchanged. No further releases are planned under the `fips-tcp-endpoint` name.

For new development with Nostr VPN's independently evolved implementation, use [`nvpn-fips-tcp-endpoint`](https://crates.io/crates/nvpn-fips-tcp-endpoint). Source: [`mmalmi/fips-tcp`](https://github.com/mmalmi/fips-tcp).

For the original FIPS project, see [`jmcorgan/fips`](https://github.com/jmcorgan/fips).
